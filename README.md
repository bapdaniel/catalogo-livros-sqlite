# Catálogo de Livros com SQLite

Aplicação de terminal para cadastrar, listar, buscar, editar e excluir livros em um banco SQLite. O banco é criado automaticamente na primeira execução.

## O que pratiquei

- fundamentos de bancos de dados relacionais
- comandos SQL (`CREATE`, `INSERT` e `SELECT`)
- integração entre Python e SQLite
- organização do código em funções
- testes automatizados

## English summary

Beginner-friendly Python and SQLite catalog with full CRUD operations, parameterized SQL queries and automated tests.

## Como executar

```bash
python app.py
```

## Como testar

```bash
python -m unittest discover -s tests
```

Projeto educacional desenvolvido durante o início do curso de Análise e Desenvolvimento de Sistemas.
